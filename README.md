# وصلة ميديا — موقع معرض الأعمال

موقع ثابت (HTML + CSS + JS) بدون أي build أو مكتبات خارجية. عربي RTL بشكل أساسي مع تبديل
للإنجليزية LTR، ووضع فاتح وداكن.

**Wasla Media portfolio site** — a dependency-free static site. Arabic-first (RTL) with an
English (LTR) toggle, plus light and dark themes.

---

## معلومات التواصل

كلها في `assets/js/data.js` تحت `WASLA.site`:

| الحقل | الوضع الحالي | المطلوب |
|---|---|---|
| `whatsapp` | فاضي | رقمك بصيغة دولية، بدون `+` وبدون مسافات — مثال `970599123456` |
| `email` | فاضي | بريد شغّال فعلًا |
| `social.facebook` / `tiktok` / `linkedin` / `youtube` | فاضية | حطّ الرابط أو اتركها فاضية لتختفي من الموقع |

**الموقع بيشتغل حتى لو تركتهم فاضيين.** كل أزرار التواصل بتتبع هالترتيب تلقائيًا:

```
واتساب  →  إيميل  →  إنستغرام
```

فطالما الأول فاضي بتنزل للتاني، وهكذا. ما في زر ميت بأي حالة. أول ما تضيف رقم
الواتساب بتتحوّل كل الأزرار عليه لحالها بدون أي تعديل تاني.

> البريد لازم يكون على دومين حقيقي. أي عنوان بينتهي بـ `.gaza` بيتجاهله الكود
> لأنو `.gaza` مش نطاق موجود أصلًا بجذر الإنترنت.

## تشغيل الموقع محليًا

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

> افتح عبر خادم محلي مش بالضغط المزدوج على `index.html` — بعض المتصفحات بتمنع
> تحميل الملفات من `file://`.

## إضافة أعمال جديدة

### 1. جهّز الصور

```bash
pip install Pillow                                   # أول مرة فقط
python3 tools/optimize-images.py ~/Downloads/legend legend
```

السكربت بيحوّل الصور لنسختين WebP (كاملة + مصغّرة)، بيتجاهل المكرر، وبيطبع لك
مقتطف جاهز للصق.

### 2. الصق المقتطف في `assets/js/data.js`

داخل مصفوفة `WASLA.projects`:

```js
{
  id: 'legend',
  client: 'LEGEND',
  title: { ar: 'تصميم باقات خدمات', en: 'Service Package Designs' },
  category: ['graphic'],              // انظر جدول التصنيفات تحت
  cover: 'legend-01',
  summary: { ar: '…', en: '…' },
  tags: { ar: ['تصميم'], en: ['Design'] },
  images: [
    { file: 'legend-01', caption: { ar: 'باقة الانطلاقة', en: 'Starter package' } },
  ],
},
```

خلص. فلاتر المعرض بتتحدّث لحالها حسب التصنيفات المستخدمة فعليًا.

### التصنيفات المتاحة

| المعرّف | الخدمة |
|---|---|
| `branding` | إنشاء وإدارة العلامات التجارية |
| `web` | إنشاء وتصميم مواقع الويب |
| `apps` | إنشاء وتطوير البرامج والتطبيقات |
| `social` | إدارة صفحات السوشيال ميديا |
| `graphic` | تصميم الجرافيك |
| `video` | إنتاج الفيديوهات |
| `ads` | الحملات الإعلانية |
| `subs` | اشتراك تطبيقات |

المشروع الواحد بيقبل أكثر من تصنيف: `category: ['graphic', 'social']`.

## إضافة نتيجة "قبل وبعد"

في `WASLA.results` داخل نفس الملف:

```js
{
  handle: 'account_name',
  url: 'https://www.instagram.com/account_name',
  field: { ar: 'المجال', en: 'Field' },
  note:  { ar: 'شو عملنا بالضبط', en: 'What we did' },
  before: { followers: 97,    posts: 15  },
  after:  { followers: 17400, posts: 117 },
},
```

نسبة النمو والشريط والعدّاد بتتحسب لحالها. رقم "متابع أضفناه لحسابات عملائنا" في
الهيدر كمان بيتجمّع تلقائيًا من كل النتائج — ما بتحتاج تعدّله يدويًا.

## بنية الملفات

```
index.html                     الصفحة كاملة (هيكل فقط، بدون محتوى ثابت)
assets/css/styles.css          كل التنسيقات — متغيّرات CSS للألوان والمسافات
assets/js/data.js              ← المحتوى: خدمات، نتائج، أعمال، تواصل
assets/js/i18n.js              ← نصوص الواجهة عربي/إنجليزي
assets/js/main.js              العرض والتفاعلات
assets/img/brand/              الشعار (SVG) + صورة المشاركة og.png
assets/img/projects/           صور الأعمال (WebP، نسخة كاملة + مصغّرة)
tools/optimize-images.py       أداة تجهيز الصور
```

الفصل مقصود: **`data.js` و `i18n.js` للمحتوى، والباقي للكود.** بتقدر تشتغل على
الموقع لسنين بدون ما تفتح `main.js`.

## النشر

الموقع ثابت بالكامل وما في فيه ولا دومين مكتوب — بيشتغل صح على أي رابط ترفعه عليه.

### Vercel

اربط الريبو من لوحة Vercel وبس. ملف `vercel.json` جاهز:

- Framework Preset: **Other**
- Build Command: **فاضي**
- Output Directory: **فاضي** (أو `.`)

الصور بتتخزّن بالكاش سنة كاملة، بينما `data.js` و `styles.css` بيتحدّثوا فورًا —
فلما تضيف أعمال جديدة بتظهر على طول بدون ما المستخدم يعمل hard refresh.

### أماكن ثانية

- **GitHub Pages** — Settings ← Pages ← اختر الفرع والمجلد `/`
- **Netlify** — اسحب المجلد، بدون أي إعدادات build
- **استضافة عادية** — ارفع الملفات بـ FTP

### بعد ما يصير عندك دومين

الروابط في `index.html` نسبية عن قصد (`canonical` و `og:image`)، والزواحف بتحلّها
مقابل رابط الصفحة — فما في إشي لازم تعدّله. بس لو حابب أقصى توافق مع كل تطبيقات
المشاركة، بتقدر تخليهم مطلقة:

```html
<link rel="canonical" href="https://your-domain.com/">
<meta property="og:image" content="https://your-domain.com/assets/img/brand/og.png">
<meta property="og:url" content="https://your-domain.com/">
```

## ملاحظات

- الصور بصيغة WebP فقط (دعمها اليوم يتجاوز 97% من المتصفحات) — أخف بـ 4 أضعاف من JPEG.
- الخطوط من Google Fonts: **Tajawal** للعربي و **Space Grotesk** للإنجليزي.
- نموذج التواصل ما بيحتاج خادم: بيبني رسالة واتساب جاهزة ويفتحها. لو ما في رقم
  مضبوط، بيرجع للبريد الإلكتروني.
- كل الحركة بتحترم `prefers-reduced-motion`، وحركات الظهور مربوطة بـ `html.js`
  فلو تعطّل الجافاسكربت المحتوى بيضل ظاهر.
